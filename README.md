# Simple Interest Calculator

A simple web-based application to calculate simple interest based on principal amount, rate of interest, and time period.

## Formula Used
Simple Interest (SI) = (P × R × T) / 100

Where:
- P = Principal amount
- R = Rate of interest (per year)
- T = Time (in years)

## Features
- Takes user input for Principal, Rate, and Time
- Calculates and displays the Simple Interest
- Clean and responsive UI
